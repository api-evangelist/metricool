Metricool is a social media management platform that helps creators, marketers, and agencies plan, schedule, and analyze content across multiple networks. It offers tools for content calendar, performance analytics, social ads reporting, and AI‑assisted post generation. Users can integrate Instagram, TikTok, YouTube, Threads, Twitter, and more, with features like hashtag tracking, competitor analysis, and campaign dashboards. Metricool also provides a certification program and educational resources for social media professionals.

**Areas:** Company · Social Media · Marketing · Analytics · Software-as-a-Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Metricool: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
